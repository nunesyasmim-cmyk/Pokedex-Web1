# Pokédex — Projeto Web 1

Projeto desenvolvido como atividade final da disciplina de Web 1, com o objetivo de aplicar os conhecimentos adquiridos em desenvolvimento web.

**Sobre o projeto**

A Pokédex é uma aplicação web que permite visualizar informações sobre Pokémon, reunindo recursos de estruturação, estilização e interatividade.

**Tecnologias utilizadas**

* **HTML5:** estruturação da página.
* **CSS3:** estilização e organização visual.
* **JavaScript:** funcionalidades e interatividade.

**Componentes do projeto**

Os principais arquivos da aplicação estão organizados na pasta Estrutura-ProjetoWeb1:

* **index.html:** responsável pela estrutura da aplicação.
* **style.css:** responsável pela aparência e estilização.
* **app.js:** responsável pelas funcionalidades e interações.

**Como executar**

1. Baixe ou clone o repositório.
2. Abra a pasta Estrutura-ProjetoWeb1.
3. Execute o arquivo index.html em um navegador.
